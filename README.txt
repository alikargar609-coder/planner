ساخت APK پلنر
=============
روش ۱ (آسان، بدون نصب چیزی): GitHub
  1) یک مخزن (repo) جدید در GitHub بسازید و محتوای همین پوشه را داخلش آپلود کنید (پوشه .github هم باشد).
  2) تب Actions > Build APK > Run workflow
  3) بعد از چند دقیقه فایل Planner-APK را از بخش Artifacts دانلود کنید و روی گوشی نصب کنید.

روش ۲: Android Studio
  1) Android Studio را باز کنید > Open > همین پوشه
  2) Build > Build APK(s)  → فایل app-debug.apk ساخته می‌شود.

اطلاعات داخل خود گوشی ذخیره می‌شود.
